# Data Model: 项目代码中文注释添加

**Feature**: 001-add-chinese-comments  
**Date**: 2025-11-25  
**Status**: Complete

## 概述

本功能主要是文档/注释工作，不涉及数据库或持久化存储。以下定义用于追踪注释进度和管理注释任务的概念模型。

## 实体定义

### SourceFile（源文件）

表示需要添加注释的代码文件。

| 属性 | 类型 | 说明 |
|------|------|------|
| `path` | string | 文件相对路径 |
| `language` | enum | 编程语言：`typescript`, `tsx`, `go`, `yaml`, `makefile` |
| `module` | string | 所属模块/包名 |
| `layer` | enum | 架构层级：`domain`, `application`, `api`, `infra`, `arch`, `common`, `feature` |
| `isAutoGenerated` | boolean | 是否为自动生成文件 |
| `hasChineseComments` | boolean | 是否已包含中文注释 |
| `commentCoverage` | number | 注释覆盖率（0-100%） |
| `lastModified` | datetime | 最后修改时间 |

### CommentableElement（可注释元素）

表示文件中需要添加注释的代码元素。

| 属性 | 类型 | 说明 |
|------|------|------|
| `file` | SourceFile | 所属文件 |
| `type` | enum | 元素类型：`package`, `interface`, `struct`, `function`, `class`, `component`, `hook` |
| `name` | string | 元素名称 |
| `lineNumber` | number | 起始行号 |
| `isPublic` | boolean | 是否为公共/导出元素 |
| `hasComment` | boolean | 是否已有注释 |
| `commentQuality` | enum | 注释质量：`none`, `partial`, `complete` |

### CommentBatch（注释批次）

表示一批需要添加注释的文件集合。

| 属性 | 类型 | 说明 |
|------|------|------|
| `id` | string | 批次标识（如 batch-1, batch-2） |
| `name` | string | 批次名称 |
| `priority` | enum | 优先级：`P1`, `P2`, `P3` |
| `scope` | string | 范围描述 |
| `files` | SourceFile[] | 包含的文件列表 |
| `status` | enum | 状态：`pending`, `in_progress`, `completed`, `verified` |
| `estimatedCount` | number | 预估文件数 |
| `completedCount` | number | 已完成文件数 |

### CommentTemplate（注释模板）

表示标准化的注释格式模板。

| 属性 | 类型 | 说明 |
|------|------|------|
| `id` | string | 模板标识 |
| `language` | enum | 适用语言 |
| `elementType` | enum | 适用元素类型 |
| `template` | string | 模板内容（带占位符） |
| `example` | string | 使用示例 |

## 关系图

```
CommentBatch (1) ----contains----> (*) SourceFile
SourceFile   (1) ----contains----> (*) CommentableElement
CommentTemplate (1) ---applies--> (*) CommentableElement
```

## 状态转换

### SourceFile 注释状态

```
[未注释] --添加注释--> [已注释] --复查通过--> [已验证]
                           |
                           +--复查不通过--> [需修改] --修改--> [已注释]
```

### CommentBatch 状态

```
[pending] --开始处理--> [in_progress] --完成添加--> [completed] --抽样验证--> [verified]
                              |
                              +--发现问题--> [in_progress]
```
